🚀 RAG Pro - Intelligent Hybrid RAG & AI HR Assistant

Enterprise-Grade AI Platform for Document Q&A and Candidate Matching

📋 Project Overview

RAG Pro is a full-stack, production-ready AI platform combining two core modules:

  • Playbook & Document Q&A RAG - Hybrid semantic + keyword search with LLM-powered context generation
  • AI HR Candidate Matcher - Deterministic scoring, skill normalization, and evidence retrieval for resume screening
  • Agentic AI Engine - Multi-agent workflow orchestration using LangGraph state machine
  • JWT Authentication - Secure user registration, login, and token-based authorization
  • SSE Streaming - Real-time word-by-word token streaming via Server-Sent Events

🤖 Agentic AI Engine (LangGraph)

Graph Architecture

Multi-node state machine for query routing and tool execution:

START │ └─→ analyze_query_node (intent detection) │ └─→ route_by_intent (conditional routing) │ └─→ tool_execution_node (execute RAG/HR tools) │ └─→ response_generation_node (compose answer) │ └─→ END

State Definition

Field Type Purpose
messages List LangGraph message history (add_messages reducer)
user_query str Original user input
intent str Detected query intent (RAG, HR, etc.)
job_id Optional[str] Target HR job context
selected_tool Optional[str] Tool to execute (RAG, HR functions)
tool_result Optional[str] Result from tool execution
final_response Optional[str] LLM-generated final answer

Tools Available

  • RAG Tools - Query playbook, search documents
  • HR Tools - Get candidate info, leaderboard, scores
  • Action Tools - Create jobs, upload files, analyze candidates

🔑 Key Files Deep Dive

server.py - Application Entry Point

  • Initializes FastAPI app with title & description
  • Mounts CORS middleware (allow all origins)
  • Includes 4 routers: API, Auth, HR, Agent
  • Serves static files from ./static directory
  • Startup event: Initialize databases & rebuild retrievers

app/core/config.py - Centralized Configuration

  • Settings class loads .env variables with sensible defaults
  • Paths: Upload dir, Chroma path, Database paths
  • JWT: Secret key, algorithm, expiration (24 hours)
  • LLM: Groq API key, model name (llama-3.3-70b-versatile)
  • Embedding: sentence-transformers/all-MiniLM-L6-v2
  • Retrieval tuning: chunk size, overlap, top-k, reranker-n

app/core/llm_factory.py - LLM Management

  • Queries Groq API for available models
  • Auto-fallback to preferred model if requested model unavailable
  • LRU cache for LLM instances
  • Fallback preference order: llama-3.3-70b → llama3-8b → mixtral

app/services/rag_service.py - RAG Orchestration

  • rebuild_retrievers() - Incremental indexing orchestration
  • Change detection via index_registry.json mtime comparison
  • BM25 cache rebuilt only when files change
  • query_rag_service() - Full RAG pipeline (search → rerank → generate)
  • stream_query_rag_service() - SSE token streaming

app/services/scoring_engine.py - Deterministic Scoring

  • calculate_candidate_score() takes analysis_result + jd_requirements
  • Set intersection matching for skills (normalized)
  • Weighted aggregation: req_skills (40%) + exp (25%) + project (15%) + pref (10%) + edu (5%) + domain (5%)
  • Zero LLM hallucination: Pure Python math
  • Returns: final_score, fit_category, score_breakdown

app/db/base_db.py - Database Context Manager

  • Context manager for database connections (get_db_connection)
  • Ensures proper connection closing & transaction handling
  • Works with both user_db & hr_db modules

Key Performance Optimizations

  • Incremental indexing - Only process changed files
  • BM25 pickle cache - Sub-5-second startup
  • LLM instance LRU caching - Reuse ChatGroq instances
  • Hybrid search - Combine dense + sparse for speed & accuracy
  • FlashRank early stopping - Top 4 chunks sufficient
  • SSE streaming - Progressive rendering in frontend
